# 🍹 Tap Tapoica Cafe

**[🚀 Посмотреть сайт](https://ohhhalina.github.io/tap-tapoica/)**

## 📋 Описание
Современный и стильный веб-сайт для кафе "Tap Tapoica". Представляет меню, информацию о заведении и создает приятную атмосферу для посетителей.

## ✨ Особенности
- 🎨 Элегантный и современный дизайн
- 📱 Полная адаптивность для всех устройств
- 🍹 Привлекательное представление меню и напитков
- 📍 Информация о местоположении и контактах
- ⚡ Быстрая загрузка и плавные переходы
- 🌟 Приятные визуальные эффекты и анимации

## 🛠 Технологии
- **Frontend**: HTML5, CSS3, JavaScript
- **Стилизация**: Modern CSS (Flexbox/Grid)
- **Интерактивность**: Vanilla JavaScript
- **Адаптивность**: Mobile-first подход
- **Шрифты**: Google Fonts
- **Иконки**: Font Awesome / Custom Icons
